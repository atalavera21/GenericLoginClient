Proyecto Identity

Sistema de autenticación y gestión de usuarios desarrollado con Angular y .NET Core

Este proyecto es una implementación completa de un sistema de autenticación moderno que demuestra diversas técnicas y mejores prácticas para la gestión de identidad en aplicaciones web.

Características implementadas

Autenticación básica

Implementación de registro de usuarios con validación de email y contraseña segura utilizando ASP.NET Core Identity.

Confirmación por email

Proceso de verificación mediante token enviado al correo electrónico para activar cuentas de usuario.

Autenticación externa

Integración con proveedores OAuth como Google, Facebook y Twitter para inicio de sesión simplificado.

Autenticación de dos factores

Implementación de verificación adicional mediante aplicaciones autenticadoras como Microsoft Authenticator.

Recuperación de contraseña

Flujo completo de "olvidé mi contraseña" con tokens de restablecimiento y validación segura.

Gestión de perfil

Capacidad para que los usuarios actualicen sus datos personales y preferencias de seguridad.

Tecnologías utilizadas

Frontend

  • Angular 19 - Framework frontend
  • PrimeNG - Componentes UI
  • PrimeFlex - Sistema de grid
  • TypeScript - Lenguaje de programación

Backend

  • ASP.NET Core 8 - Framework backend
  • Entity Framework Core - ORM
  • Identity - Sistema de autenticación
  • JWT - Tokens de autenticación

Sobre este proyecto

Este proyecto fue desarrollado como demostración de implementación de autenticación avanzada, migración desde un sistema MVC tradicional a una arquitectura moderna con API RESTful y Angular. El código está diseñado para ser claro, mantenible y seguir las mejores prácticas actuales.
